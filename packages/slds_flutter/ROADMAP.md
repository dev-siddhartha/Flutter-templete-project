# SLDS Flutter Roadmap

## Alpha 0.1

- Deliver Tier 1 components from the Figma `SLDS_Alpha v0.1` file.
- Deliver Tier 2 components from the available Figma `SLDS_Alpha v0.1` nodes and document component mappings where dedicated source nodes are not available.
- Wire token parity checks, accessibility checks, widget-state tests, and visual regression checks to CI.
- Capture manual TalkBack and VoiceOver evidence for Button, Input, and Checkbox in English, Sinhala, and Tamil.

## Alpha 0.2

- Harden Tier 2 manual accessibility evidence across English, Sinhala, and Tamil.
- Add Android 8 low-end device evidence for 2GB-3GB RAM devices.
- Add package adoption telemetry guidance for component reuse and consistency.

## Beta

- Freeze public component APIs.
- Publish migration guides for Alpha API changes.
- Publish package distribution process and version support matrix.
